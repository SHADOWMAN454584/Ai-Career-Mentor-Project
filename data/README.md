# Data workflow

Do not claim evaluation results from the demo application. For the capstone report, document the source, licence, preprocessing, train/validation/test split, and limitations of each dataset.

- `placement/`: public campus-placement data; map source columns to CGPA, project count, internship count, skills, branch, and placed label.
- `resumes/`: only consented and de-identified resumes. Store annotations outside version control if they contain personal information.
- `courses/`: curated public course metadata with verified links.
- `roles/`: role requirements derived from official skills taxonomies and reviewed job descriptions.
